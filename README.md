# نظام درجات الابتدائي — التحديثات

هذا المستودع **لتوزيع التحديثات فقط** — لا يحتوي كود البرنامج.

- كل إصدار جديد يُنشر في [Releases](../../releases) ومعه ملف التنصيب `primary-grades-setup-x.y.z.exe`.
- البرنامج عند المدرسة يفحص هذا المستودع (الإعدادات ← تحديثات البرنامج)، ويعرض ملاحظات كل إصدارٍ فاته،
  ويأخذ نسخة احتياطية من القاعدة قبل التنزيل ثم يثبّت التحديث.
- بيانات المدرسة (الطلاب والدرجات والنتائج والإعدادات) محفوظة خارج مجلد البرنامج، والتحديث لا يمسّها.

**أول مرة**: المدرسة التي عندها إصدار أقدم من 0.4.0 تنزّل ملف التنصيب من صفحة الإصدار وتشغّله بيدها مرةً واحدة —
ومن بعده يكتشف البرنامج التحديثات وحده.
